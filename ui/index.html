    What this view does not tell you

    • A valid receipt means the recorded history has not changed since it was signed. It does not mean the task was safe or correct, or that anything really happened.
    • A signed approval shows that a key signed. It does not show which person held that key.
    • A valid hash proves the bytes match what was committed. It does not prove a page was truthful.
    • A score from the injection guard or an anomaly rule is a signal for review. It is not proof of an attack.
    • Unknown and not independent are never passes. Missing evidence stays missing.
