Sign in to your company workspace

Paste the company certificate (HCORG1…) and your own access key (HCMEM1…). Your company admin makes them on their own computer; this page never sees a private key. They are checked here, in your browser, and kept on this device only.

Customer issues BUILT

Drop what a customer sent: the record (.abbreceipt with its .keys.json, or a sandbox receipt) and, if there is one, a note named name.issue.json. Every record is checked first. One that does not check out is listed as NOT INCLUDED and never counted.

    Issues BUILT

    Issues from verified records. A Member sees the ones assigned to them; a Boss sees all of them and assigns.

      Members and keys BOSS ONLY BUILT

      Keys are made on the company admin's computer with tools/make_license.py; this page only prepares the command and lists people. Revoking takes effect where the company's signed revocation list has been imported (NOT ENFORCED by a server).

      Locked: only a Boss can manage members and keys.

        Escalated holds BOSS ONLY BUILT
        
            
        A Member escalates an issue (a POLICY_HOLD); a Boss approves or rejects it. The decision is a note kept in this browser with the Boss's name and the day. It is not signed and not enforced.
        
            
        Locked: only a Boss can approve or reject.
        
            
          
          
          

          
          
            
          Customer issues and next-phase insights BOSS ONLY BUILT
          
            
          Counts from VERIFIED records only. Records that did not check out are shown beside them as NOT INCLUDED and never change the ranking. Categories come from the customer's note or the record's words: a claim, not proof.
          
            
          Locked: only a Boss can see the insights.
          
            
          
          
          
        
          

        
          
          
          What to know
          
          
            
            
          • BUILT Company certificates, Boss and Member access keys, expiry and a signed revocation list, all checked in the browser.
            • 
            
          • NOT ENFORCED There is no server. Another company's key cannot open this company's workspace here, but anyone with this browser's developer tools can read this browser's storage.
            • 
            
          • PLANNED A central server for real access control, shared data between devices, single sign-on and signed audit logs.
            • 
            
          • Reports and counts are summaries, not proofs, and are not legal or compliance advice.
