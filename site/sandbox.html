Gatekeeper Sandbox

Try the gate. Then try to break the record.

Send an AI agent on four test flights. A fixed policy decides each one, a budget caps the money, a person signs the risky one, and every step lands in a hash chain you can edit to see it fracture.

SIMULATION · fake money · runs in this tab · nothing leaves it

Everything here is made in your browser with its own Web Crypto: SHA-256 for the chain and an ephemeral ECDSA P-256 key for the signature. It uses a simplified format so each step is visible. It is not the real receipt format: abb verify cannot read a sandbox receipt, and the numbers are smaller than the real spend tiers so you can reach every branch.

This browser cannot run Web Crypto here (it needs a secure context), so the sandbox cannot start. Open it over https or from a local file.
