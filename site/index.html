A flight recorder for AI agents

Every agent action, on the record.

Attach HashCam to an AI agent. It records what the agent does, holds risky steps for your passkey, and seals a signed receipt anyone can check offline.

Get it on GitHub See how it works

This is the public showcase. HashCam itself runs on your own computer: the recorder, the extension and the HashCam Console. This site does not watch any agent and collects nothing.

Attach HashCam to an agent

Browser agents

BUILT

Claude in Chrome, Comet, browser-use, or you, in Chrome or Edge.

  1. Start the recorder: python tools/recorder.py --dsn …
  2. Load the extension/ folder (Developer mode, Load unpacked).
  3. Open its side panel, pair, register your passkey.
  4. Open the agent's tab, set the passport, press Record this tab.

PLANNED

Custom agents

BUILT

Your own agent reports each step to the local recorder API.

  1. POST /sessions: task, agent name, passport.
  2. POST /sessions/{id}/events: navigate, form_submit, download, secret.
  3. POST /sessions/{id}/stop: seals the receipt.

Full examples are in the console that ships with the repo.

Connect to your recorder

Run python tools/recorder.py on this computer, then paste the viewer key from ~/.hashcam/recorder-viewer-key. The viewer key can only look at sessions; it cannot start, approve or stop anything. Your browser may ask to let this site reach devices on your local network: allow it. The key stays in this tab only.
